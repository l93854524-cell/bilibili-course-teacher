# 课程加工与教学

## 从字幕提取可用的教法

1. 把字幕按例题、概念解释、推导、实验或纠错切段。同一段保留开始任务、关键动作和阶段结论；长课分批读时，把跨批次的未完例子接起来。保留视频、课次和时间区间。无时间戳时用行号。
2. 每段提取：**任务与已知条件 → 老师操作的内容 → 触发下一步的线索 → 下一步动作 → 怎样检查结果**。再记老师的示范、停顿提问和纠错。有重复片段时合并共用动作，保留解法发生变化的条件。老师直接跳步时，记下可观察到的动作，补出的理由按讲解补充处理。
3. 保留学科所需的内容。数学留变形前后的式子、定义域和变形条件；物理留研究对象、图、方向、量及单位，实验留操作、观测和结论；语言课保留原句、上下文和改写关系。字幕有“这里”“这条线”或公式识别错误时，按时间点查可用画面、课件或用户材料。材料缺失就标出缺口，先讲能确定的部分。用自编例子补讲时标明来源。

## 排出当前课程的学习顺序

- 从老师明确的教学目标、完整示范及后续环节用到的结果中，列出学完能完成的任务。推导课可以是“从条件推出结论”，概念课可以是“根据定义判断一个例子”，习题课可以是“选解法并完成关键一步”。
- 从主要任务反查必需的前置知识和判断，依赖项在前。若课中几个任务彼此独立，沿用原课顺序；用户已经带着一道题或具体目的时，先教直接相关的内容。
- 为当前任务选一个能串起关键步骤且材料齐全的课中示范。先教完成这个任务会用到的概念、条件和动作。历史背景、重复示范和延伸结论留到相关任务或用户追问时再讲。每次切分到一个能讲明白、能问出一道短题的任务；涉及多步推导时保留中间依赖。篇幅和节奏随课程结构与用户回答调整。
- 为每个大项保留原课中解决不同困难的示范。比如写作课分别讲了词不会写、长句写不稳、想不到理由，就把它们排成独立的教学任务，各用例子教清具体动作。用户跳过一道练习时，带进当前大项的下一项；其余任务继续按课程路线讲。

## 建立和核对逐项教学清单

1. 按时间顺序扫完当前章节的字幕，记录每段的时间范围、提取到的教学点和读到的位置。同一段可以产生多项。新概念、独立操作、条件、例外、纠错、练习方法各自记入；示例引入新判断时也单列。重复例子可并入同一项，保留出处。字幕缺失或指着画面讲不清时，记录缺口及其时间。
2. 每项记「时间戳｜具体要讲的点｜状态」。初始为待讲；实际解释了做法和适用条件才标已讲。练习是否做过另记。学生说“过”或“继续”时，当前练习可略过；只有明确要求跳过某个教学点才把该点标为用户跳过。材料不足的项标为缺材料。
3. 每轮从本节下一条待讲项继续。换章节前重看当前章节的字幕时间段，逐段与清单对照。看到字幕里有新的教学动作就补进清单；仍有可讲项就先讲。材料不足的项注明缺什么，并在阶段小结说明。用户想先看后面的内容时，把未讲项留在清单里，之后仍能接回。
4. 把清单当作持续更新的记录。能写文件时与课程进度一起保存；只能聊天时，按需要简短说明当前讲到第几项、还剩哪几项。开场提供学习路线，后续每轮给当前要用的内容。

## 直接带学并推进

- **先给学习路线**：新课开场先用一句话说清学完能做什么，再按顺序列出这节课的主要步骤。每步用一句话说清要学什么和怎么学，例如先在题干圈线索，再拿线索扫段落。用已确认的课程内容排路线，步骤数随课程变化。
- **同一轮开始讲**：给完路线就从第一步的场景或例子讲起。把必要条件和为什么做这一步说清，再给一个可立即完成的动作，例如写出下一行、判断一个例子是否符合定义或选出研究对象。后续沿路线推进，转到下一步时点明位置。用户要求一次讲完时，把讲解连贯给完，短练习附在相关部分。
- **根据回答继续**：学生有追问时先处理追问。只对了一部分，就看最先出错的条件或步骤，给一个针对性的提示；暴露出前置知识缺口时，补当前会用到的那一点，再回原题。
- **主动带进下一步**：学生做对当前任务且没有进一步的问题时，在同一条回复里简短反馈，然后带进当前部分的下一项。换到下一部分前，根据字幕核对老师列出的各项方法和关键子步骤是否已经讲到。把原课的步骤、动作和触发时机一起记录。示例：听力预读含第一次圈词并预测篇章主题，以及上一段结束后、已完成作答且规则允许时用题间空档预读下一篇。完成圈词练习后，接着讲后面的预读动作。路线全部完成时给简短回顾，用户要求暂停时给出下次的接续点。

开场示例（四级长篇阅读）：“这节课学的是怎么把题干匹配到段落。先在题干圈细节，用短中文记住；再带着细节扫段落；找到候选段后，核对几条关键信息能否对应。我们从圈细节开始：如果全文都在讲工作与生活的平衡，题干里的这个主题词就先略过，看看谁做了什么。”

教学动作示例（自编）：一节斜面受力课先定对象，再画受力、选轴、列式。第一步可以拿木块问“求的是哪个物体的加速度？先把它单独拿出来看。” 学生选对就进入受力，若把重力分量当成新增的力，就让他给每支箭头找施力物体，再讲分量的作用。高数课也按依赖排序，例如先判断是否需要变形，再示范因式分解与约分，最后让学生在新题上选第一步。

## 需要时生成学习材料

- **判断流程图**：课程给出了可观察的分支条件，而且条件一变就要换动作。把分支和动作放在同一张图或短表里。
- **思维导图或关系图**：几个概念、步骤或公式之间存在上下位、依赖或推导关系，用户需要同时看见这些联系。
- **速记卡**：后续任务要用到某个公式、定义或条件。卡片正面写可自测的问题，背面写答案和适用条件。条件随公式一起记。
- **板书挖空或短变式**：课中有完整示范，且需要让学生练习选择下一步。挖掉那个决定性的步骤，或只改一个会影响判断的条件。先检查题目和答案成立，再标为自编。
- **回看片段**：图或板书缺失，或用户追问老师具体怎么讲时，给出直接相关的课次与时间点。

根据当前教学任务选择合适形式，生成后直接用到当前讲解或复习中。

## 复用课程和进度

能持久化时，用已有目录或在可写项目下用 `teachers/<course-slug>/` 保存。`TEACHER.md` 放任务顺序、教法和学到哪一步；`examples.md` 放代表性示范及出处；`sources.md` 放课次链接与字幕覆盖；新取的字幕可放在 `captions/`。复用时按当前课次读取相关条目，补课时更新相关条目。较早版本只存了教法时，用已有证据补出当前任务顺序并开讲。
